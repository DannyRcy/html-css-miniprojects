# Ejercicio 03 - Landing Page con Flexbox

Se desarrolló una landing page con estructura moderna y responsive utilizando HTML y CSS puro.

## Qué incluye

- Header con navigation bar flexible:
  - `display: flex`
  - `justify-content: space-between`
  - `align-items: center`
- Sección Hero principal con:
  - título llamativo
  - párrafo descriptivo
  - botón CTA con estilos interactivos
- Sección de características (Features) con 3 columnas usando Flexbox:
  - `display: flex`
  - `gap: 20px`
  - `flex-wrap: wrap`
  - cards con `flex: 1 1 280px`

## Estructura del proyecto

- `index.html` — contenido de la página
- `styles.css` — estilos y layout con Flexbox

## Vista previa

Se puede abrir el archivo `index.html` directamente en el navegador o servir la carpeta con un servidor local.

## Resultado

La página queda con un diseño limpio, visualmente atractivo y adaptado para escritorio y dispositivos móviles.
