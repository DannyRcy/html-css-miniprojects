# Ejercicio 05 - Pricing Cards

## Descripción
Se desarrolló una sección de precios con tres tarjetas de planes (`Starter`, `Pro` y `Business`) en una estructura HTML y CSS moderna y responsiva.

## Requisitos implementados
- Variables CSS en `:root` para centralizar colores, tipografías y sombras.
- Plan destacado `Pro` resaltado con `transform: scale(1.05)`.
- Badge `Recomendado` posicionado con `position: absolute` sobre la tarjeta principal.
- Botones con estilos para estado normal, `:hover` y `:active`.
- Diseño limpio y visualmente equilibrado con fondo degradado, sombras suaves y tarjetas con bordes/redondeados.

## Variables CSS utilizadas
```css
:root {
  --primary-color: #6802c1;
  --accent-color: #63aee6;
  --text-color: #212322;
  --card-bg: #ffffff;
}
```

## Archivos creados
- `index.html`
- `styles.css`

## Vista previa
Se puede abrir el archivo `index.html` directamente en el navegador o servir la carpeta con un servidor local.
