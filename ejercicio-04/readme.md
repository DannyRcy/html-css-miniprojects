# Ejercicio 04 - Galería Fluida

Se desarrolló una galería responsive con CSS Grid y diseño moderno para cumplir con los requisitos indicados.

## Qué se implementó

- Grilla fluida con `grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))`
- Espaciado entre tarjetas con `gap`
- Ajuste de imágenes con `object-fit: cover` para evitar distorsiones
- Efectos hover con `transform: scale(1.03)` y transición suave
- Adaptación móvil mediante `@media (max-width: 768px)` para ajustar padding y tipografías

## Archivos

- `index.html`: estructura de la galería
- `styles.css`: estilos y responsividad

## Vista previa

Se puede abrir `index.html` directamente en el navegador o servir la carpeta con un servidor local.
